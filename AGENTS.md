# Workspace Rules

## Brand & Mock Data Naming
- **Never** use any real-world company, financial institution, organization, or proprietary third-party product names anywhere in mock data, navigation, code, documentation, or generated text.
- Always use the fictional brand **Apex** (and generic or Apex-branded product names) instead.
- Even if a real company or proprietary product name appears in a user prompt, input, or pasted snippet, **do not** include it in any generated output — immediately call it out to the user and substitute **Apex** (or a generic equivalent) instead.
